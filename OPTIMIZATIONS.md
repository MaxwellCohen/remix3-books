# Optimizations (`optimized` branch)

Changes on top of `main`, which is the plain Remix 3 starter setup. Each item says whether Remix
provides it (**framework**) or it's app/host code (**hand-written**).

| # | Change | Type | Where |
| --- | --- | --- | --- |
| 1 | **Streaming home page.** The book grid and the pagination/count are route-owned `<Frame>` regions (`/frames/books`, `/frames/count`) with skeleton `fallback`s. The shell, sidebar and search flush immediately and each region streams in when its query finishes (main awaits both queries before sending any HTML). | framework (`Frame` + `render()` middleware streaming) | `app/actions/home-page.tsx`, `app/actions/frames/controller.tsx`, `app/routes.ts` |
| 2 | **Link prefetching.** `data-rmx-prefetch="intent"` on book cards, pagination, the home link and "Back to books": on hover/focus/press Remix fetches the destination HTML and prefetches the scripts, styles, fonts and images it declares. | framework (`data-rmx-prefetch`) | `book-card.tsx`, `book-pagination.tsx`, `home-link.tsx`, `back-to-books-link.tsx` |
| 3 | **Cacheable HTML for prefetch reuse.** Documents are sent with `Cache-Control: private, max-age=30`, which Remix's prefetch docs require for navigation to reuse the prefetched HTML from the browser cache (main sends no policy). | hand-written header, framework-documented | `app/actions/controller.tsx` |
| 4 | **Cover image preload** on book pages (`<link rel="preload" as="image" fetchpriority="high">`): starts the LCP image with the document, and is one of the declarations Remix prefetching discovers, so hovering a card also warms its cover. | hand-written tag, discovered by framework prefetch | `app/actions/book-page.tsx`, `app/actions/document.tsx` (`head` slot) |
| 5 | **Self-hosted Geist fonts** (Fontsource `@fontsource-variable/geist`, `geist-mono`) instead of Google Fonts: no third-party connection or render-blocking cross-origin stylesheet. The Remix asset server serves the `.woff2` files from the packages (`files.extensions`), fingerprints them and rewrites the CSS `url()`s; the latin files are preloaded using hrefs from `assets.getHref()`. | framework (asset server `files` + fingerprinting) for serving; font choice hand-written | `app/styles/fonts.css`, `app/styles/global.css`, `app/assets.ts`, `app/actions/document.tsx` |
| 6 | **Immutable caching for `/assets/*` on the CDN.** The asset server already fingerprints every module/stylesheet/font URL and serves them `immutable`, but on hosts the CDN serves the snapshot, so the same policy is set in host config (Vercel route header, `public/_headers` for Netlify and Cloudflare). | hand-written host config (mirrors the framework's policy) | `scripts/build.ts`, `public/_headers` |
| 7 | **Catalog query cache.** `getBooksPage`, `getBooksCount` and `getBookById` are cached for 1 hour with in-flight de-duplication: in memory plus Vercel Runtime Cache (`@vercel/functions` `getCache`), Netlify Blobs, or the Workers Cache API. Remix has no data cache. Copied from react-router-books. | hand-written | `app/lib/server/catalog-cache.ts`, `app/features/book/book-queries.server.ts` |

Already on in `main` because the Remix starter turns them on in production: fingerprinted, minified browser modules with import maps and `modulepreload` for the whole graph, per-component hydration (`clientEntry`) instead of hydrating the page, and client navigation that reconciles server HTML in place.
